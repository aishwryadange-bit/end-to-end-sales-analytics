# 📈 End-to-End Sales Analytics

## 🎯 Objective

To analyze sales growth and business performance by combining data cleaning, database management, and interactive visualization.

## 🛠️ Tools

- Python
- SQL / MySQL
- Power BI
- Excel

## 📊 Dashboard Highlights

- Monthly Sales Growth
- Regional Profit Analysis
- Product-wise Sales
- Total Sales & Profit KPIs
- Profit Percentage
- Year & Region Filters

## 📁 Project Structure

- `data` – Source dataset
- `python` – Data cleaning and analysis notebook
- `powerbi` – Power BI dashboard
- `screenshots` – Dashboard preview
